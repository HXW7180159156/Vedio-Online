# Vedio-Online
A lightweight browser video player for magnet links.

## Live Demo / 在线运行

https://hxw7180159156.github.io/Vedio-Online/

## Features
- Paste any `magnet:?` link and stream directly in the browser
- Automatically finds common video files in the torrent
- Supports selecting files when a torrent includes multiple videos

## Usage
1. Open https://hxw7180159156.github.io/Vedio-Online/ in a modern browser.
2. Paste a magnet link.
3. Click **播放** to start streaming.

> Note: playback depends on WebRTC support and available peers.
